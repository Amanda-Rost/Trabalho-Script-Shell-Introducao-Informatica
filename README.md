## 📋 Sobre o Projeto

Este projeto consiste em um **Script Shell** demoninado **Administrador de Contas**, permitindo automatizar tarefas de gerenciamento de usuários no sistema Linux Ubuntu.

---

## 🚀 Como Executar

### 1️⃣ Dar permissão de execução ao script

```bash
sudo chmod +x administrador-de-contas.sh
```

### 2️⃣ Executar o programa

```bash
sudo ./administrador-de-contas.sh
```

#### 🎉 Pronto! Agora é só aproveitar nosso Administrador de Contas :D
